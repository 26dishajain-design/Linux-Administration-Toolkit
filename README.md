# Linux Administration Toolkit

## Project Overview
The Linux Administration Toolkit is a menu-driven project developed using Bash scripting in Ubuntu Linux.

## Features
1. System Information
2. CPU Information
3. Memory Usage
4. Disk Usage
5. Network Information
6. User Information
7. Folder Backup
8. Activity Logs
9. Exit

## Technologies Used
- Ubuntu Linux
- Bash Scripting
- Linux Commands
- Git and GitHub

## How to Run

```bash
chmod +x main.sh
./main.sh
```
